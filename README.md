# Электронная библиотека СПбГУ (учебный проект)

Каталог книг по экономике, программированию и праву:
- **фонд института**: 28 книг, из них 19 PDF (учебники, монографии, журналы «Правоведение» и «Морское право», законы, книги на узбекском);
  читаются прямо на сайте, есть **полнотекстовый поиск**, работает без интернета;
- **Open Library**: бесплатный API без ключа, полные книги открываются через Internet Archive.

Без сборки и без сервера, только HTML, CSS и JavaScript.

## Поиск
- По названию, автору, темам, издательству, описанию и **тексту каждой страницы** PDF (распознан OCR) и глав учебных текстов.
- Кириллица и латиница взаимозаменяемы: `siyosatshunoslik` найдёт «Сиёсатшунослик», `zvekov` — «Звеков».
- Узбекские ў/қ/ғ/ҳ и o'/g', разные окончания слов (страхование/страхования), опечатки до 1–2 букв.
- В результатах — фрагмент найденного текста с номером страницы; клик открывает читалку на этой странице.
- Подсказка «Возможно, вы искали…», фильтры: источник, тип издания, язык, годы, тема, сортировка.
- Поиск по фонду мгновенный и работает без интернета (источник «Фонд института»).

## Как запустить
- **Быстро:** откройте `index.html` двойным кликом. Всё работает, включая фонд института.
- **Как на хостинге (рекомендуется):** запустите локальный сервер в папке проекта
  - `npx serve .` (нужен Node.js), или
  - `python -m http.server 8000` → http://localhost:8000, или
  - расширение **Live Server** в VS Code.
- **Публикация:** загрузите папку целиком на GitHub Pages, Netlify или любой статический хостинг.

## Как добавить жанр
Одна строка в `js/config.js`, массив `GENRES`:
```js
{ id: 'medicine', subject: 'medicine', ru: 'Медицина', uz: 'Tibbiyot', icon: 'heart', subs: ['anatomy', 'pharmacology'] },
```
Жанр сам появится в меню, ленте жанров на главной, каталоге, полках и подвале.
По желанию добавьте в `js/i18n.js`:
- описание: `'genre.medicine.desc'`;
- переводы подкатегорий: `'subj.anatomy': 'Анатомия'` (без перевода подкатегория выводится как есть, на английском).

`subject` — это тема Open Library. Проверить, сколько по ней книг: https://openlibrary.org/subjects/medicine

## Как добавить язык фильтра
Одна строка в `js/config.js`, массив `LANGUAGES`. Код — трёхбуквенный MARC (так язык хранится в Open Library):
```js
{ code: 'kaz', ru: 'Казахский', uz: 'Qozoq tili' },
```

## Как добавить PDF-книгу в фонд
**Полный вариант (с просмотром страниц и поиском по тексту):**
1. Положите файл в `books/pdf/`, например `books/pdf/my-book.pdf` (имя = id книги: латиница, цифры, дефис).
2. Добавьте описание в `tools/catalog.json`: скопируйте любую запись и поменяйте `id`, `genre`, `type`, `title`, `author`, `year`, `languages`, `subjects`, `description`.
   `coverPage` — номер страницы с обложкой, `ocrLang` — языки распознавания (`rus`, `rus+eng`, `deu+eng`).
3. Запустите `python tools/build_library.py` (нужны Python, Pillow, pytesseract, poppler и Tesseract — подробности в начале скрипта).

**Быстрый вариант (без программ):** добавьте запись прямо в `data/local-books.js` с `"format": "pdf"` и `"pdf": "books/pdf/my-book.pdf"`.
Книга появится в каталоге и откроется во встроенном просмотрщике PDF браузера; по тексту страниц она искаться не будет.

## Ограничения Open Library
- **Узбекских книг мало.** По фильтру «Узбекский» результатов обычно единицы. Сайт показывает об этом подсказку.
- **Полных книг мало.** `ebook_access = public` — это в основном издания, перешедшие в общественное достояние (часто до 1929 года), почти все на английском.
  Фильтр «Только полные книги» включён по умолчанию. При пустом результате сайт предлагает снять его одной кнопкой.
- **У части книг нет обложки или описания.** Для них показываются фирменная заглушка и пометка «Описание не добавлено».
- **PDF есть не у каждой книги Internet Archive.** Ссылка `/download/{ia}/{ia}.pdf` в редких случаях отдаёт 404;
  встроенная читалка (`archive.org/embed`) при этом работает.
- **«Фрагмент» (borrowable) полностью не открывается.** Полную версию Open Library выдаёт по своим правилам после регистрации. Сайт эти ограничения не обходит.
- **Лимиты API.** Сайт делает не больше 1 запроса в секунду, кэширует ответы на 30 минут и отменяет устаревшие запросы.
- **Параметр `language` в адресе запроса не фильтрует книги**, а только влияет на порядок результатов (так сказано в документации).
  Поэтому язык, годы, тема и доступ передаются внутри `q`: `language:rus ebook_access:public first_publish_year:[1990 TO 2024]`.

## Читалка PDF
- **Страницы** (по умолчанию): страницы показываются заранее подготовленными изображениями. Так работает везде: на телефоне, без сервера, при открытии двойным кликом.
  Есть миниатюры, номер страницы, переход ← →, масштаб и режим «по ширине»; номер страницы сохраняется в адресе и в «Продолжить чтение».
- **PDF**: оригинальный файл во встроенном просмотрщике браузера (на ПК). Кнопки «Скачать PDF» и «Открыть PDF» есть всегда.
- Присланные PDF — ознакомительные фрагменты (обложка, титульный лист, оглавление), так они и подписаны на сайте.
  Полные тексты книг, защищённых авторским правом, выкладывайте только с разрешения правообладателя.

## Безопасность
- Все данные из API выводятся через `escapeHtml`. Идентификаторы (`/works/OL…W`, `ia`) проверяются регулярными выражениями до подстановки в ссылки.
- Ввод пользователя очищается от спецсимволов синтаксиса Solr.
- В `index.html` задан Content-Security-Policy: скрипты только свои, запросы только к openlibrary.org, фреймы — archive.org и карты.
- Встроенная читалка Internet Archive открывается в `iframe` с `sandbox`.
